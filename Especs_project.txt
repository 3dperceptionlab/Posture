Tenemos ya desarrollado el PC de control con ROS 2 controlando el robot y sacando la pose del operario.
Ahora queremos desarrollar el proyecto del servidor donde se irán almacenando los datos (del robot y de la persona) y se creará una interfaz web para visualizar esos datos.
Queremos un Docker en Ubuntu donde conviva las bases de datos, la API y el dashboard web, todo ello conectado y documentado para poder moverlo a otro servidor en el futuro.
A continuación, se muestra un esquema de todos los módulos del sistema.

PresentAtAngle: presentar la pieza a una altura e inclinación determinadas.

HoldAndRotate: sujetar y rotar la pieza de forma controlada.

ConfirmQuality: confirmar una operación de inspección o calidad.

YieldToHuman: ceder el control ante una intervención humana.


POSTURE no pretende que el operador programe o reenseñe el robot. Pretende que pueda intervenir con acciones sencillas como:

Start.

Slow.

Pause.

Nudge.

Resume.

Cancel.

Stop.
